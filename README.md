# Manejo de scripts

Una lista de tareas para agregar pendientes y marcarlos como hechos.

Al subir cambios a `main`, GitHub Actions prepara los archivos y corre las pruebas. Si pasan, publica la aplicación en GitHub Pages.

- [Documento de la práctica](Manejo-de-Scripts.docx)
- [Aplicación publicada](https://yilinroux.github.io/Manejode-scrip/)
- [Ejecuciones del pipeline](https://github.com/YilinRoux/Manejode-scrip/actions)
